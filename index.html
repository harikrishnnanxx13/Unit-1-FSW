Module 01

The Foundation — HTML Basics & Structure

Understand the purpose of HTML, its syntax, and how to structure a basic web page.

1 Hour Beginner

Learning Objective

By end of this module you will be able to create a valid, structured HTML document with proper tags, attributes, and comments.

1.1

What is HTML?

10 mins

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page using elements called tags.

Think of HTML as the skeleton of a webpage. CSS adds the skin and clothes, while JavaScript adds behavior and movement.

HTML Document Structure

Every HTML document follows a standard structure:

HTML 
<!DOCTYPE html>  <!-- Declares the document type -->
<html>           <!-- Root element of an HTML page -->
<head>           <!-- Meta-information about the document -->
    <title>My First Page</title> <!-- Title in browser tab -->
</head>
<body>           <!-- Visible page content -->
    <h1>Hello, World!</h1>
    <p>This is my first paragraph.</p>
</body>
</html>

Document Anatomy

<!DOCTYPE html>
Tells browser this is HTML5
<html>
Root container for everything
<head>
Invisible metadata & links
<body>
Visible content goes here

Attributes

The Three Core Selectors

Selects all elements of a given type. Good for general defaults.

CSS — Element Selector
/* Selects ALL h1 tags on the page */
h1 {
    color: green;
    font-size: 2rem;
}

/* Selects ALL paragraphs */
p {
    line-height: 1.6;
}

Selects elements with a specific class. Classes can be reused on multiple elements. Prefixed with .

HTML + CSS — Class Selector
<!-- HTML -->
<p class="highlight">This is highlighted.</p>
<span class="highlight">This too!</span>

/* CSS */
.highlight {
    background-color: yellow;
    font-weight: bold;
}

Selects a single unique element. IDs must be unique per page. Prefixed with #. Use sparingly.

HTML + CSS — ID Selector
<!-- HTML -->
<p id="main-paragraph">
    This is the main paragraph.
</p>

/* CSS */
#main-paragraph {
    font-weight: bold;
    font-size: 1.2rem;
}

Module 05

The Box Model & Layout

Master the CSS Box Model — the foundation of all web layout.

1 Hour Intermediate

Learning Objective

Control spacing around elements using margin, padding, border. Understand how box-sizing affects dimensions.

5.1

The CSS Box Model

45 mins

Every HTML element is rendered as a rectangular box. This box has four layers:

MARGIN (transparent)
BORDER
PADDING (transparent)
CONTENT
width × height

Margin

Space outside the border. Creates distance between elements.

.box {
  margin: 20px;           /* all sides */
  margin: 10px 20px;     /* top/bottom left/right */
  margin: auto;           /* centers horizontally */
}

Border

The line around padding. Has width, style, and color.

.box {
  border: 2px solid black;
  border: 3px dashed red;
  border-radius: 8px; /* round corners */
}

Padding

Space inside the border, between border and content.

.box {
  padding: 20px;       /* all sides */
  padding-top: 10px;
  padding-left: 15px;
}

Content

The actual content area. Sized with width and height.

.box {
  width: 300px;
  height: 200px;
  background-color: lightblue;
}
Critical: box-sizing Property

By default, width only applies to the content area. Adding padding and border increases the total size unexpectedly. Fix this globally:

CSS — Global Best Practice
/* Add this to the TOP of every stylesheet! */
*, *::before, *::after {
    box-sizing: border-box;
}
/* Now: width = content + padding + border (no surprises!) */

Module 07

Introduction to Bootstrap

Set up Bootstrap and build responsive layouts with the 12-column grid system.

1 Hour Intermediate

Learning Objective

Include Bootstrap via CDN, use containers, rows, and columns, and understand responsive breakpoints.

7.1

What is Bootstrap?

15 mins

Bootstrap is a free, open-source front-end framework for building responsive, mobile-first websites faster. It gives you pre-built CSS and JS components.

Mobile-First

Designed to look great on phones first, then scales up

Grid System

Powerful 12-column grid for complex layouts

Components

Ready-to-use UI components: buttons, cards, navbars...

Speed

Build beautiful UIs much faster than writing CSS from scratch

7.2

Including Bootstrap via CDN

15 mins
HTML — Bootstrap CDN Setup (Copy this!)
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Bootstrap Demo</title>
    <!-- Bootstrap 5 CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>

    <h1>Hello, Bootstrap!</h1>

    <!-- Bootstrap 5 JS (needed for interactive components) -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

Module 10

Putting It All Together — Project Day

Build a complete, responsive personal blog/portfolio using everything you've learned.

1 Hour Capstone

Learning Objective

Synthesize HTML, CSS, and Bootstrap skills to build a fully responsive, multi-section webpage from scratch.

Project Requirements Checklist

Header Navbar

Bootstrap navbar with brand name and navigation links (Home, About, Blog, Contact)

Hero Section

Large intro section with .display- heading, .lead paragraph, and CTA button

About Section

Two-column layout (col-md-8 text, col-md-4 photo/image)

Blog Posts Section

3 Bootstrap cards in a responsive col-md-4 grid with image, title, text and button

Contact Form

Form with Name, Email, Message textarea, and styled submit button

Footer

Centered copyright text with .text-muted and a background color class

Step-by-Step Build Guide

01

Setup (5 mins)

Create index.html. Add Bootstrap 5 CDN in <head>. Create and link style.css for custom overrides.

02

Build the Navbar (10 mins)

Use Bootstrap's <nav class="navbar"> component. Customize brand and links. Add navbar-expand-lg for responsiveness.

03

Build Hero Section (10 mins)

Use a .container with centered text. Add .display-4 heading, .lead paragraph, and .btn .btn-primary button.

04

About & Blog Sections (15 mins)

Create about section with .row .col-md-8 .col-md-4 layout. Then create 3-card blog grid using .row .col-md-4.

05

Contact Form & Footer (15 mins)

Build form with .form-control inputs and labels. Add footer with .bg-dark .text-white .text-center classes.

06

Review & Test (5 mins)

Resize the browser to test responsiveness. Use DevTools (F12) to inspect styles. Check all links and form fields work.
